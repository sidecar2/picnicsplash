# filtering-patterns

Vite + React demo for exploring **filter chip** and related menu filtering UI, using the local `picnic-eater-components` package.

## Run locally

From the **picnic-eater-components** repo root, build the library once if you have not:

```bash
npm run build
```

Then:

```bash
cd filtering-patterns
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`).

## Deploy

Same as other apps in this monorepo: point your host at this directory, run `npm install` and `npm run build`, and serve the `dist` output (or use your platform’s Vite preset).
